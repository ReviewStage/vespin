Manage workspaces and members, environment variables, GitHub, repositories, cloud setup, Slack, Sentry, integrations, keys, and models. Every command also takes the global flags `--json`, `-q`, `-w`, and `--url`, described in [CLI](/cli#scripts-and-coding-agents).

## vespin workspace list

List your workspaces, the default marked *

```sh
vespin workspace list [flags]
```

```sh
# Your workspaces
vespin workspace list

# Their ids alone
vespin workspace list -q
```

## vespin workspace use

Keep a workspace as the default for commands on this service

```sh
vespin workspace use [flags] <workspace>
```

| Argument or flag | What it does |
| --- | --- |
| `workspace string` | The workspace's slug or id |

```sh
# Act in the acme workspace from now on
vespin workspace use acme
```

## vespin workspace remove

## vespin env set

Set a variable every cloud agent in the workspace is handed, its value read from stdin and never shown again

```sh
vespin env set [flags] <name>
```

| Argument or flag | What it does |
| --- | --- |
| `name string` | The variable's name, such as DATABASE_URL |

```sh
# Type the value; it is not echoed
vespin env set DATABASE_URL

# Read it from a file, one trailing newline dropped
vespin env set DATABASE_URL < url.txt

# Pipe it from a script
printf %s "$TOKEN" | vespin env set NPM_TOKEN
```

## vespin setup edit

Replace the workspace's install script, or a repository's setup script, from a file or stdin

```sh
vespin setup edit [flags]
```

| Argument or flag | What it does |
| --- | --- |
| `--repo string` | A repository's setup script, as owner/name, rather than the install script |
| `--file, -F string` | The whole script, from a file or - for stdin; an empty one removes it |

```sh
# Save the install script

# Remove it
vespin setup edit --repo acme/app -F /dev/null
```

## vespin setup actions

List each repository's run actions, the commands a member runs in its cloud agents' sandboxes from the Run menu, and add, edit, or remove one

## vespin setup actions add

Add a run action to a repository's list, last unless --position says

```sh
vespin setup actions add [flags]
```

| Argument or flag | What it does |
| --- | --- |
| `--repo string` | The repository, as owner/name, in any casing |
| `--label string` | What the Run menu and the action's Terminal tab call it |
| `--command string` | The bash it runs from the checkout, such as 'pnpm dev' |
| `--emoji string` | One emoji for its icon |
| `--glyph string` | A Lucide icon for its icon, by its kebab-case name, such as rocket |
| `--color choice` | With `--glyph`, the color it wears (choices: red, orange, yellow, green, teal, blue, purple, pink) |
| `--position integer` | Its place in the list, from 0; past the end is the last |
| `--default` | Make it the default, which the Run button runs |

```sh
# The Run button's action
vespin setup actions add --repo acme/app --label 'Dev server' --command 'pnpm dev' --default

# Another, with an emoji
vespin setup actions add --repo acme/app --label Tests --command 'pnpm test' --emoji 🧪

# Keep the new action's id
id=$(vespin setup actions add --repo acme/app --label Lint --command 'pnpm lint' -q)
```

## vespin setup actions edit

Change one run action in only what the flags name; its id stays

```sh
vespin setup actions edit [flags] <action>
```

| Argument or flag | What it does |
| --- | --- |
| `action string` | The action's id, as `vespin setup actions` lists it |
| `--repo string` | The repository, as owner/name, in any casing |
| `--label string` | What the Run menu and the action's Terminal tab call it |
| `--command string` | The bash it runs from the checkout, such as 'pnpm dev' |
| `--emoji string` | One emoji for its icon |
| `--glyph string` | A Lucide icon for its icon, by its kebab-case name, such as rocket |
| `--color choice` | With `--glyph`, the color it wears (choices: red, orange, yellow, green, teal, blue, purple, pink) |
| `--position integer` | Its place in the list, from 0; past the end is the last |
| `--clear-icon` | Wear the Run menu's own icon again |
| `--default` | Make it the default, which the Run button runs; `--no-default` makes it no longer the default |

```sh
# A new command
vespin setup actions edit <id> --command 'pnpm dev --port 3001'

# Make it the default
vespin setup actions edit <id> --default

# Move it first
vespin setup actions edit <id> --position 0
```

## vespin slack set

Set your Slack notifications, the workspace's default repository for Slack starts, or a channel

```sh
vespin slack set [flags]
```

| Argument or flag | What it does |
| --- | --- |
| `--notifications choice` | Whether the bot writes you, in Slack, the threads that wait on you (choices: on, off) |
| `--repo string` | The repository Slack starts work in where a message names none, as owner/name; none clears it. With `--channel`, that channel's own |
| `--channel string` | A channel to change, by its id or its name as slack show lists them |
| `--join` | With `--channel`: put the bot in it, a public channel alone |
| `--leave` | With `--channel`: take the bot out of it, forgetting its repository |

```sh
# Stop the bot writing you
vespin slack set --notifications off

# Slack starts work in acme/app
vespin slack set --repo acme/app

# Put the bot in #eng, its starts in acme/api
vespin slack set --channel eng --join --repo acme/api

# Take the bot out of #eng
vespin slack set --channel eng --leave
```
