---
title: "Slack"
description: "Start agents from Slack and hear back there"
---

Vespin's Slack bot starts an agent when you mention @Vespin or DM it. Your workspace's agents then answer in Slack as the bot.

## Connect the bot

An owner or admin connects it once per workspace: **Connect** on the **Slack** row under **Workspace connections** in **Settings › Workspace**. A Vespin workspace connects to one Slack workspace.

Once connected, the **Slack** row opens the bot's page. Under **Channels**:

- **Default repository**: where agents started from Slack work when nothing else says.
- **Add channel**: adds the bot to a public channel. For a private channel, run `/invite @Vespin` in it.
- Each channel can have its own repository, which overrides the default.

## Start an agent

Mention @Vespin in a channel the bot is in, or DM the bot. The bot starts an agent on a new task assigned to you. The agent reads the earlier messages in the thread, and the images and PDFs your message shares.

The agent picks a repository in this order:

1. An `owner/name` written in your message.
2. The channel's repository.
3. The workspace's default repository.
4. The repository of your most recent agent.

The agent reacts and replies in the thread itself. The bot posts there only when a turn fails, is stopped, or hits a usage limit. Reply in that thread, with or without @Vespin, to send the agent another message. A thumbs-up or thumbs-down reaction on one of the bot's messages there reaches the agent as feedback.

## Agents in Slack

In a workspace with the bot connected, every agent can read the channels the bot is in, private ones included, and post, react, and DM members there as the bot. A reply in a thread an agent posted in reaches that agent.

To stop agents from DMing you, turn off **Slack notifications** under **Notifications** in **Settings › Preferences**. The setting is yours alone and applies in every workspace.

## How Vespin finds you

The bot matches your Slack account to Vespin by a Slack account you linked in **Settings › Integrations**, or else by your email. If it can't match you, it starts nothing and asks you to link your Slack account.
