`vespin` is Vespin's command-line tool. It does what the app does from a shell: create tasks, start and follow agents, check out their branches, and answer your Inbox. It prints JSON for scripts and for coding agents that call it.

## Install

On a Mac with the app, open **Settings › Vespin MCP & CLI** and click **Install**. Anywhere else, use one of these:

```sh
# Node 20 or later
npm i -g vespin

# Bundles its own Node; macOS on Apple silicon, or Linux on x64 or arm64
curl -fsSL https://vespin.dev/install.sh | sh -s cli

# Run once without installing
npx vespin --help
```

The curl install puts `vespin` in `~/.local/bin`, which must be on your `PATH`. `vespin version` prints the version and how it was installed. `vespin update` updates a curl install in place, and prints the command to run for npm, pnpm, yarn, bun, or npx.

## Sign in

```sh
vespin login
```

It opens your browser. On a machine with no browser, such as one you reach over SSH, run `vespin login --no-browser` and paste back the address your browser lands on. `vespin whoami` shows the account and its workspaces.

On a Mac the sign-in is kept in the login Keychain. Elsewhere it's kept in `~/.config/vespin/credentials.json`, readable only by you. `vespin logout` signs this machine out. **Sign out everywhere**, in the **CLI** section of Settings › Vespin MCP & CLI, signs out every machine.

## Choose a workspace

A command acts in one workspace, chosen in this order:

1. `-w` or `--workspace <slug>` on the command.
2. The `VESPIN_WORKSPACE` environment variable.
3. The default you set with `vespin workspace use <slug>`.
4. Your only workspace, if you're in one.

If none of these settles it, the command lists your workspaces and exits with code 2.

## Work from a repository

`vespin task create` reads the repository from the folder's `origin` unless you pass `-R owner/name`.

```sh
# Create a task here, with an agent on it
echo "Fix the login redirect" | vespin task create "Login redirect" --prompt -

# Stream the agent's turn, or block until it ends
vespin agent logs <agent> --follow
vespin agent wait <agent>

# Message the agent
echo "Also cover the signup page" | vespin agent send <agent> -F -

# Fetch its branch into this checkout
vespin agent checkout <agent>
```

`--prompt` and `-F` take a file path, or `-` to read stdin, never the text itself. `agent checkout` needs the agent's branch pushed and a clean working tree.

A task can be named by its id, its number, or its key, such as `ACME-42`.

## Answer your Inbox

```sh
# Open threads, unread marked ●
vespin inbox list

# A thread and its open ask
vespin inbox view <thread>

# Pick an option, done or not-done for a to-do, or your own words
vespin inbox answer <thread> <answer>

# Write on the thread without answering
echo "Use the staging database" | vespin inbox reply <thread> -F -
```

## Scripts and coding agents

Output is text at a terminal, and JSON when piped or with `--json`. `-q` (`--quiet`) prints only ids, one per line. With JSON or `-q`, `agent logs --follow` prints once, when the turn ends. Notes and errors always go to stderr.

A command that asks for confirmation needs `-y` (`--yes`) when stdin isn't a terminal. It never reads a `y` from stdin.

The exit code says how a command ended:

| Code | Meaning |
| --- | --- |
| 0 | Done |
| 1 | Refused |
| 2 | Usage error |
| 3 | Not signed in |
| 4 | Unreachable, or a server error |
| 5 | The agent's turn failed or was stopped (`--wait` and `agent wait` only) |
| 6 | Timed out waiting |

| Variable | What it does |
| --- | --- |
| `VESPIN_WORKSPACE` | The workspace to act in, after `-w` |
| `VESPIN_URL` | The service to use, as `--url` sets it |
| `VESPIN_TOKEN` | A bearer token used before the stored sign-in, never renewed or stored |

The npm package ships a skill, `skills/vespin/SKILL.md`, that teaches a coding agent the commands, `--json`, and these codes. For Claude Code, copy the `skills/vespin` folder into `~/.claude/skills/`. For Codex and Cursor, add the skill's text to your `AGENTS.md`. To connect an agent to Vespin without a shell, use [Vespin MCP](/vespin-mcp) instead.
