---
title: "Integrations"
description: "Connect your accounts at other services so your agents can use their tools"
---

An integration gives your agents the tools of an account you have at another service, such as Linear or Notion. Agents use those tools as you, so they can see and do what your account can.

## Connect an account

Integrations belong to you, not to a workspace. In **Settings › Integrations**, click **Connect** next to a service and sign in. If a sign-in expires later, click **Reconnect**.

The **GitHub** integration uses the GitHub account you sign in to Vespin with. It's separate from the GitHub connection in **Settings › Workspace**, which gives agents access to your repositories.

Connecting **Slack** also lets Vespin's Slack bot recognize you. See [Slack](/slack).

## Services

Which services you see can depend on your account.

| Service | What agents get |
| --- | --- |
| Executor | The apps, APIs, and skills you set up in Executor |
| GitHub | Issues, pull requests, and code, as you |
| Gmail | Read mail and write drafts. Agents can't send mail. |
| Google Calendar | Events, invitations, and free time |
| Google Drive | Docs, sheets, and files |
| Granola | Meeting notes and transcripts |
| Linear | Issues, projects, and cycles |
| Mercury | Accounts, transactions, and payments. An approver confirms payments in Mercury. |
| Neon | Postgres projects, branches, and SQL |
| Notion | Pages, databases, and comments |
| PostHog | Analytics, feature flags, and experiments |
| Resend | Send email and read delivery logs |
| Sentry | Errors, traces, and releases |
| Slack | Messages, channels, and threads |
| Stripe | Payments, customers, and subscriptions. You approve refunds and money movements in Stripe. |
| Supabase | Postgres, auth, storage, and edge functions |
| Vercel | Deployments, logs, and domains |
| Y Combinator | Bookface companies, founders, and investors |

## More than one account

Some services let you connect more than one account, such as two Notion workspaces. Choose **Add another account** from the **⋯** menu, and use **Rename** to tell them apart. When an agent isn't sure which account you mean, it asks before making changes.

## What agents get

Every agent you start can use every tool from your connected integrations, including tools that make changes. Automation runs get them too, since they run as you.

To turn an integration off for one agent, open **MCP servers** from the **+** menu in its message box. You can also `@`-mention a server to give the agent access for its next turn only.

Anything a tool returns, including a credential, ends up in the agent's transcript and is sent to its model.

## Disconnect

Choose **Disconnect** from the **⋯** menu. Vespin revokes its access at the service, and agents lose the account on their next call. Other accounts at the same service stay connected.

From a terminal, use `vespin integrations`. See [Workspace](/cli/workspace).
